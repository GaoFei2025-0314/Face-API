这个页面仅用于本机或内网联调。正式业务前端不要直接保存或发送 API Key，应由业务后端代理注入 X-API-Key。

联调页面需要填写 API Key。正式上线时，浏览器只应持有业务系统 session/token，不应持有 face_api 的 X-API-Key。

标准流程

  1. 1接入配置待检查
  2. 2摄像头授权待打开
  3. 3Register待注册
  4. 4Login + 活体待登录
  5. 5最近 audit待刷新

Login 默认流程：创建 challenge -> 连续采集帧 -> 提交 challenge -> 采集登录图 -> 调用 /auth/face-login。

Register 默认流程：采集单人脸图片 -> 调用 /faces/register。若后端开启注册活体，或你在配置中选择“先做 challenge”，则会先完成 register challenge。
