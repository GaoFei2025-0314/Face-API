# 实施计划：性能与规模化能力

## 范围

规划后续版本实现以下能力：

- 5 万人脸 benchmark。
- 批量导入和导出报告。
- 搜索性能报告。
- 可选 index 方案的触发条件和状态可见性。
- 精确搜索回退路径。

## 设计决策

- benchmark 先于 index。
- 默认继续使用精确搜索。
- 批量任务必须输出可核对报告。
- index 如进入实现，必须可关闭、可重建、可回退。

## 验证

- 使用样例或生成数据运行 benchmark。
- 验证批量导入成功/失败/跳过统计。
- 验证 search/login 耗时指标可复现。
- 验证 index 状态和回退语义。
