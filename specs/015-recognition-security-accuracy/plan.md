# 实施计划：识别安全与准确率增强

## 范围

规划后续版本实现以下能力：

- 人脸质量评分和失败原因细分。
- 更完整的 login/register audit。
- terminal 级策略摘要和人工调参建议。
- 活体能力边界说明和测试样本报告。
- 安全默认值和人工复核流程。

## 设计决策

- 不自动调整阈值，只提供建议。
- 不为了通过率降低默认安全策略。
- 质量指标必须可解释，方便现场排障。
- 活体能力说明必须保守，不承诺企业级 anti-spoofing。

## 验证

- 构造无人脸、多脸、低质量、活体失败、相似度不足等样本。
- 验证失败原因和 audit 字段可区分。
- 验证样本不足时调参报告不会给出激进建议。
- 验证文档覆盖活体能力边界。
