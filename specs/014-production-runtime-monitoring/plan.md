# 实施计划：生产运行与监控

## 范围

规划后续版本实现以下能力：

- 启动脚本可靠性和启动前检查。
- 停止脚本和端口释放排障。
- 健康检查和监控脚本。
- 日志轮转或日志清理策略。
- 生产恢复流程加固。
- 运维文档和故障处理清单。

## 设计决策

- 继续以 Windows PowerShell / bat 脚本为主要操作入口。
- 监控以本地脚本和 REST health/config/status 接口为主，不引入外部监控平台。
- 生产恢复优先离线恢复，在线恢复只作为受控开发/单进程维护窗口能力。
- 启动输出可以提示配置是否存在，但不能打印 API secret。

## 验证

- 模拟端口被占用时启动脚本能给出清晰提示。
- 模拟未设置 API Key 时启动输出能明确提醒。
- 启动后 health-check 脚本能通过。
- 停止脚本能停止 reloader 和 server 子进程。
- 日志轮转或清理策略有测试或可复现验证。
