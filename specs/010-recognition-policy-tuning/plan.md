# 实施计划：识别策略调参

## 范围

实现识别策略档案和基于 audit 的调参建议：

- terminal 绑定策略档案。
- 策略只生成建议，不自动修改阈值。
- 无效策略值在生效前拒绝。
- 未绑定 terminal 使用默认策略档案。

## 设计决策

- 策略配置以服务本地配置为主，不引入用户账号或权限系统。
- login 使用 terminal 对应策略阈值；注册继续使用注册质量策略。
- 调参建议基于近期 audit 中的相似度、成功状态和失败原因生成。

## 验证

- 测试默认策略档案。
- 测试 terminal 绑定策略档案。
- 测试未知 terminal 使用默认策略。
- 测试调参建议不修改运行策略。
