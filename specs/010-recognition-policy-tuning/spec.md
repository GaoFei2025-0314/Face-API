# 功能规格：识别策略调参

**功能分支**：`010-recognition-policy-tuning`

**创建时间**：2026-06-05

**状态**：草案

**输入**：用户描述：“Roadmap v1.1 需要让识别阈值和质量策略可度量、可调整，适应真实现场使用。”

## Clarifications

### Session 2026-06-05

- Q: V1.1 的识别策略调参要做到什么程度？ → A: 只展示调参建议，不自动改策略。
- Q: 识别策略档案的作用范围怎么定？ → A: 按 terminal 绑定策略档案。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 运维人员查看当前识别策略（优先级：P1）

运维人员需要不用看代码，就能理解当前匹配阈值、注册质量规则和 login 决策策略。

**优先原因**：阈值设置错误可能会拒绝真实用户，也可能放过不安全匹配。

**独立测试**：运维人员可以查看当前识别策略，并说明它如何影响 login 和注册决策。

**验收场景**：

1. **假如** 服务正在运行，**当** 运维人员查看有效策略，**那么** 可以看到当前阈值和质量规则。
2. **假如** 策略值已文档化，**当** 复盘一次 login 决策，**那么** 运维人员可以说明哪些策略值影响了结果。

---

### 用户故事 2 - 维护人员基于 audit 证据调阈值（优先级：P1）

维护人员需要根据 audit 证据和指导，判断阈值应该收紧还是放宽。

**优先原因**：现场摄像头、光照、人群差异很大，阈值调整必须基于证据。

**独立测试**：维护人员可以查看最近成功和失败的尝试，并输出一份阈值调整建议。

**验收场景**：

1. **假如** 已有足够近期 audit 记录，**当** 维护人员请求调参摘要，**那么** 摘要展示匹配分布和建议方向。
2. **假如** audit 证据不足，**当** 维护人员请求建议，**那么** 服务提示样本不足，暂不建议调整。

---

### 用户故事 3 - 不同 terminal 使用不同策略档案（优先级：P2）

交付工程师需要为不同摄像头、安装点和光照环境的 terminal 使用不同策略档案。

**优先原因**：不同 terminal 的摄像头、角度和光照可能差异很大，按 terminal 调参更贴近现场。

**独立测试**：一个 terminal 可以关联到指定策略档案，并能独立验证该 terminal 的识别行为。

**验收场景**：

1. **假如** 存在两个策略档案，**当** 请求来自不同 terminal，**那么** 服务按对应 terminal 绑定的策略档案执行策略。

### 边界情况

- audit 数据太少，无法支持建议。
- 策略值超出安全范围。
- terminal 未绑定策略档案。
- 请求引用了未知策略档案。
- 策略变更与生产安全预期冲突。

## 需求 *(必填)*

### 功能需求

- **FR-001**：服务必须以运维人员可读的形式暴露有效识别策略。
- **FR-002**：服务必须区分注册质量策略和 login 匹配策略。
- **FR-003**：服务必须支持基于最近 audit 结果进行阈值复盘，并只生成建议，不自动修改策略。
- **FR-004**：阈值或策略变更必须由人工确认后再修改配置。
- **FR-005**：当证据不足时，服务必须明确说明不足以推荐阈值调整。
- **FR-006**：服务必须支持按 terminal 绑定命名策略档案。
- **FR-007**：terminal 未绑定策略档案时，服务必须使用明确的默认策略档案。
- **FR-008**：策略说明必须解释 false accept 与 false reject 的取舍。
- **FR-009**：无效或不安全策略值必须被拒绝，并返回清晰中文原因。

### 关键实体

- **识别策略**：识别流程使用的一组阈值和质量决策。
- **策略档案**：面向某个 terminal 的一组命名识别设置。
- **terminal 策略绑定**：terminal identity 到策略档案的对应关系。
- **调参摘要**：根据近期识别结果生成的证据和建议。

## 成功标准 *(必填)*

### 可度量结果

- **SC-001**：运维人员能在 1 分钟内查看当前识别策略。
- **SC-002**：100% 无效策略值在影响识别前就被拒绝，并返回清晰原因。
- **SC-003**：维护人员能在 5 分钟内根据近期 audit 证据生成阈值建议。
- **SC-004**：调参建议在 100% 验收场景中不会自动改变正在使用的策略。
- **SC-005**：文档至少解释 3 种常见阈值调整场景及其取舍。

## 假设

- V1.1 调参先做运维指导和安全配置，不做自动自我修改阈值。
- 服务仍不负责业务授权判断。
- 每个 terminal 可以绑定自己的策略档案；未绑定时使用默认策略档案。
