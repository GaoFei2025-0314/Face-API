# 实施计划：向量搜索扩展

## 范围

围绕 5 万人脸记录、1 秒内返回目标，补齐搜索扩展能力：

- 保持默认精确搜索。
- 增加 benchmark 工具或接口支撑容量验证。
- 暴露搜索就绪、记录数、模式和目标状态。
- 为近似搜索保留可配置扩展点，但只有 benchmark 证明需要时启用。

## 设计决策

- 当前精确搜索仍是正确性基准。
- V1.1 不强制引入外部向量库；先保证可测量、可诊断、可回退。
- 搜索缓存新鲜度必须在注册和删除后保持正确。

## 验证

- 测试搜索状态包含目标规模和目标耗时。
- 测试注册/删除后缓存失效和重载。
- 测试 benchmark 摘要结构。
- 测试默认精确搜索模式。
