# 实施计划：运维管理控制台

## 范围

实现本地运维控制台需要的后端能力和静态页面：

- 复用 `FACE_API_KEY`。
- 查看状态、配置、人脸记录、audit。
- 删除人脸记录。
- 触发备份。
- 维护模式下恢复数据库。
- 高风险操作必须二次确认。

## 设计决策

- 控制台是本地轻量页面，不引入完整账号系统。
- 恢复数据库必须先进入维护模式。
- 维护模式用于阻止恢复与正常请求并发执行。
- 页面不展示 embedding 和 API secret。

## 验证

- 测试控制台页面可访问。
- 测试受保护控制台 API 复用 API key。
- 测试删除必须确认。
- 测试恢复必须维护模式和确认。
- 测试控制台数据不包含 embedding。
