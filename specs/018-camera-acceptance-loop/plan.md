# 实施计划：摄像头注册登录闭环验收

## 范围

增强现有 `camera-integration.html`，让它成为 V1.7.1 的现场验收页面。

本计划覆盖：

- API 地址和 API Key 配置体验。
- 摄像头注册流程。
- 摄像头登录流程。
- 活体状态提示。
- 中文错误原因展示。
- 最近 login audit 展示。
- 前端接入文档同步。

## 设计决策

- 不新增 `acceptance.html`。
- 不引入 React、Vue 或其他前端框架。
- 页面允许本地直连 face_api，用于现场验收和调试。
- 文档保留生产建议：正式业务前端应通过业务后端代理调用 face_api。
- audit 展示基于页面已有 `/audit/login/recent` 能力整理增强，只做最近记录，不在本版本做复杂统计看板。
- login 成功或失败后自动刷新最近 audit，同时保留手动刷新入口。

## 验证

- 浏览器打开 `camera-integration.html`。
- 授权摄像头。
- 注册一个测试用户。
- 用同一人登录成功。
- 用错误 API Key 验证中文错误提示。
- 用不合格画面验证质量/活体错误提示。
- 查看最近 login audit 是否在 login 后自动刷新，并验证手动刷新可用。
