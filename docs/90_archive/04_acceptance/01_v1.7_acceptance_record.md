# V1.7 验收记录

> 日期：2026-06-06  
> 范围：V1.7.1 摄像头注册登录闭环验收；V1.7.2 Windows 长期运行加固

## 1. V1.7.1 页面闭环

已完成的静态和代码级验收：

- `camera-integration.html` 保持单 HTML 文件。
- 页面流程已整理为“配置 -> 摄像头 -> Register -> Login + 活体 -> 最近 audit”。
- Register / Login 结果仍通过主结果区展示。
- 最近 login audit 使用独立区域展示，不覆盖主结果。
- Login 完成后会自动刷新最近 login audit，并保留手动刷新入口。
- 活体 challenge 返回 `passed:false` 时会停止后续 register/login。
- 错误展示同时包含后端 `message`、`reason` 和本地处理建议。
- `sanitize()` 保留，继续过滤 `embedding`、`api_key`、`apiKey`。

现场人工验收建议：

1. 启动服务并设置 `FACE_API_KEY`。
2. 打开 `camera-integration.html`。
3. 填写 API 地址、API Key、terminal_id、username。
4. 打开摄像头。
5. 点击摄像头 Register。
6. 点击摄像头 Login。
7. 确认最近 login audit 自动刷新。
8. 用错误 API Key、多人脸、暗光或模糊画面验证中文错误原因。

## 2. V1.7.2 长期运行

已完成的自动化验收：

- `run-prod.bat` 支持 `FACE_PORT`，默认仍为 8000。
- `run-prod.bat` 支持 `FACE_PYTHON`，可适配不同 Python 环境路径。
- 新增 Task Scheduler 安装脚本。
- 新增 Task Scheduler 卸载脚本。
- 新增 NSSM 服务安装脚本。
- 新增 NSSM 服务卸载脚本。
- 安装/卸载脚本支持 PowerShell `-WhatIf`。
- NSSM 缺失时脚本会清晰失败，不会下载 NSSM。
- 新增 PowerShell smoke test，覆盖脚本语法、帮助信息、参数校验、NSSM 参数序列和 NSSM 缺失提示。
- Task Scheduler 使用临时任务名完成真实创建、查询和卸载，未启动 face_api 服务。

已执行验证：

```text
D:\anaconda3\envs\face_api\python.exe -m unittest tests.test_scripts_smoke -v
```

结果：

```text
8 passed
```

安全边界：

- 本次已在当前机器用 `face_api_codex_verify` 临时任务名真实创建并删除 Windows Task Scheduler 任务，未启动服务，确认没有遗留任务。
- 本机未发现 `nssm.exe`，因此未真实创建 NSSM Windows Service。
- NSSM 安装流程已通过 fake `nssm.cmd` stub 验证参数序列，并通过缺失路径负向验证确认不会下载 NSSM。
- 现场真实 NSSM 安装前必须先安装 NSSM，使用 `-WhatIf` 预览，再按 runbook 执行。
