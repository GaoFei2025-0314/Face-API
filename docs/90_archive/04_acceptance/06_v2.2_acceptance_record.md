# V2.2 现场算法验收与阈值调优台验收记录

## 版本目标

V2.2 提供独立 `acceptance.html`，用于现场验证真人、打印照片、手机屏幕照片、电脑屏幕照片和手机播放眨眼视频样例，并导出 JSON/CSV 报告和保守调参建议。

## 验收前置条件

- `face_api` 服务已启动。
- 已配置 `FACE_API_KEY`，并在 `acceptance.html` 页面填写相同的 `X-API-Key`。
- 如果通过 `http://localhost:8122/acceptance.html` 打开页面，生产模式需设置 `FACE_CORS_ORIGINS=http://localhost:8122`。
- 使用同一个测试用户做人脸注册/重绑和五类样例采集；`user_id` 使用数字或留空。
- 摄像头预览可见，现场人员能确认正脸位于画面中央。
- 自动验证命令默认使用当前激活 Python 环境；本机实际验证可记录具体 Python 路径。
